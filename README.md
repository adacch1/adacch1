## About me

I work in **finance**, and the job has taught me a little about most corners of **business**: operations, strategy, markets, and the spreadsheets behind the spreadsheets.

Code is a hobby, not a profession. When a small tool would make life easier (or more fun), I build it, or I fork someone's clever work and bend it until it fits.

- 💼 Finance by day, with a broad reach across the rest of the business

## Other things I've built

Most of these live in private repos, so the names aren't links:

- **fourC — Credit Card Control Center**: a self-hosted Vietnamese credit-card tracker with due dates, monthly payment status, and a cashback matrix per category and card. *Alpine.js + Supabase, with an Android wrapper.*
- **ielts-playground**: a self-hosted IELTS platform for Reading, Listening, and Writing, with deterministic auto-grading and optional AI essay feedback. *Next.js + Postgres + Prisma.*
- **AutoPrint**: a home web app that sends print jobs to my Windows printers from any device, tunneled in over Cloudflare. *Next.js, with every file normalized to PDF before printing.*
- **q25-lineage-installer**: a LineageOS installer for the Zinwa Q25 Pro, for macOS and Windows.
